# 🎮 CALCULADORA DE JOGOS EHPIT

### Organização inteligente de jogos e planejamento de armazenamento para diversos consoles.

A **Calculadora de Jogos EHPIT** é um projeto independente, criado com a proposta de facilitar a seleção, organização e estimativa de espaço necessário para bibliotecas de jogos de diferentes consoles.

A ferramenta oferece uma experiência visual, dinâmica e intuitiva, permitindo montar listas personalizadas, acompanhar tamanhos, comparar opções de armazenamento e gerar relatórios completos.

## 🚀 PRINCIPAIS FUNCIONALIDADES

- Identificação opcional por nome e telefone.
- Suporte a diversos consoles populares.
- Seleção individual ou múltipla de jogos.
- Seleção dinâmica entre páginas, consoles e listas.
- Pesquisa de jogos e filtros por console.
- Categorias de jogos, melhores do ano e títulos populares.
- Opção para limpar toda a seleção.

## 🎯 LISTAS DISPONÍVEIS

- Lista de jogos para PS1.
- Lista de jogos para PS2.
- Lista de jogos para Xbox 360.
- Outras listas e categorias de consoles disponíveis na plataforma.

## 📊 CALCULADORAS DINÂMICAS

O sistema organiza os jogos por classes de tamanho:

- Muito grandes.
- Grandes.
- Médios.
- Pequenos.
- Super pequenos.

Cada jogo possui uma estimativa inicial de tamanho, que pode ser ajustada manualmente pelo usuário.

## 💾 RECOMENDAÇÃO DE ARMAZENAMENTO

A ferramenta apresenta sugestões de armazenamento conforme o tamanho total da seleção:

- Pendrive.
- HD externo.
- SSD.
- Outras opções de armazenamento compatíveis.

As recomendações servem como referência de planejamento. O espaço realmente necessário pode variar conforme o formato dos arquivos e o sistema utilizado.

## 📋 LISTA DETALHADA POR CONSOLE

Durante a seleção, os jogos são adicionados automaticamente à lista personalizada.

É possível:

- Visualizar os jogos selecionados.
- Conferir o tamanho individual e total.
- Alterar o tamanho estimado de cada jogo.
- Remover jogos da seleção.
- Consultar os links informativos disponibilizados.
- Identificar se o título pertence a uma das listas EHPIT.

## 📄 RELATÓRIO FINAL

Ao concluir a seleção, o usuário pode gerar um relatório completo contendo:

- Resumo da seleção.
- Relação detalhada dos jogos.
- Organização por console.
- Tamanho individual dos títulos.
- Espaço total estimado.
- Referência de armazenamento recomendado.

O relatório pode ser copiado, colado e exportado para Word, facilitando a consulta e o planejamento.

## 🧭 NAVEGAÇÃO

A plataforma possui paginação para facilitar a consulta dos conteúdos, com opções de avançar, voltar e navegar entre as páginas disponíveis.

## 🎯 OBJETIVO DO PROJETO

Criar uma ferramenta prática para ajudar os usuários a organizar suas listas de jogos, estimar o espaço necessário e planejar melhor seus dispositivos de armazenamento.

## ⚠️ AVISO IMPORTANTE

Este projeto é uma ferramenta independente de organização, consulta e estimativa de armazenamento.

A Calculadora EHPIT não é afiliada, patrocinada ou oficialmente vinculada
